# Working-Group-NACFR

**North Atlantic Climate Food Resilience (NACFR)**

This repository stores research papers (PDF format) related to the North Atlantic Climate Food Resilience working group. Papers are organised into the following topic folders:

| Folder | Topic |
|--------|-------|
| [`AMOC_North_Atlantic_Ocean_Dynamics/`](AMOC_North_Atlantic_Ocean_Dynamics/) | AMOC & North Atlantic Ocean Dynamics |
| [`Aerosol_Forcing_Radiative_Balance/`](Aerosol_Forcing_Radiative_Balance/) | Aerosol Forcing & Radiative Balance |
| [`Jet_Stream_Atmospheric_Circulation_European_Hydroclimate/`](Jet_Stream_Atmospheric_Circulation_European_Hydroclimate/) | Jet Stream, Atmospheric Circulation & European Hydroclimate |
| [`Food_Systems_Agriculture_Supply_Chain_Risk/`](Food_Systems_Agriculture_Supply_Chain_Risk/) | Food Systems, Agriculture & Supply Chain Risk |

## Adding Papers

Place PDF files in the appropriate topic folder. Each folder contains a `.gitkeep` placeholder that can be left in place alongside the PDFs.
